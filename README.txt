LAB 06 - JAVA RMI (ECLIPSE)

Packages: lab61 den lab69, tuong ung 9 bai trong de.

Cach chay tung bai:
1. Mo project LAB06_RMI trong Eclipse.
2. Mo Server.java trong package can lam, Run As > Java Application.
3. De server chay, mo Client.java cung package, Run As > Java Application.
4. Moi package dung cong RMI 1099; dung tat server bai cu truoc khi chay server bai tiep theo.
5. Client mac dinh ket noi localhost.

So du ban dau lab66: 1,000,000 VND. Chuyen bay lab68: VN101 (100 ghe), VN202 (80 ghe), VN303 (60 ghe).

Neu Eclipse co module-info.java va bao loi RMI, thu xoa module-info.java de chay tren classpath. Khong can tao file module-info.java.
